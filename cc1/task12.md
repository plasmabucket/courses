# Время связывания переменных

#### 3 примера различного времени связывания

1) Связывание при исполнении

Курс 28z, задача №6:  
Переменная `grid_hits`:
```python
# Dictionary for translating numbers into grid coordinates
GRID_MAP: Final[dict[int, tuple[int, int]]] = {
    6: (0, 0), 1: (0, 1), 9: (0, 2),
    5: (1, 0), 2: (1, 1), 8: (1, 2),
    4: (2, 0), 3: (2, 1), 7: (2, 2)
}
...

def PatternUnlock(n: int, hits: list[int]) -> str:
    # Translation of hits to a sequence of coordinates
    grid_hits: list[tuple[int, int]] = [GRID_MAP[hit] for hit in hits]
    ...
```
Связывание `grid_hits` со значением происходит при выполнении программы. Произвести связывание в более ранний момент невозможно т.к. неизвестно значение, которое будет подано в функцию. Всё, что можно было задать заранее, было выведено в константу `GRID_MAP`.

2) Связывание при написании кода

Курс 28z, задача №6:  
Переменная `line_len`:
```python
...
def PatternUnlock(n: int, hits: list[int]) -> str:
    ...    
    line_len: int = 0
    ... # Далее идут вычисления длины линии
```
Связывание происходит максимально рано -- при написании в коде. Задача требует найти длину линии при данной последовательности введённых чисел. Логика задачи не подразумевает, что когда-то может потребоваться инициализировать переменную каким-либо другим значением, отличным от нуля, поэтому вводить именованную константу здесь нет смысла. Гибкость кода здесь не требуется.

3) Связывание при компиляции

Пример из курса ads1, задача №3:  
Поле `capacity` у класса `DynArray`:
```python
INITIAL_CAPACITY: Final[int] = 16
...

class DynArray:
    def __init__(self) -> None:
        self.count: int = 0
        self.capacity: int = INITIAL_CAPACITY
        self.array = self.make_array(self.capacity)
    ...
```
Связывание переменной `self.capacity` со значением происходит при загрузке модуля. Использование магического числа здесь неуместно т.к. вполне вероятно, что в будущем этот параметр придётся изменить. Использование же чего-то более сложного, такого как чтение файла конфигурации, здесь тоже непригодно т.к. создание динамических массивов в программе может происходить часто -- чтение файла сильно бы тормозило программу. Использование именованной константы здесь даёт необходимую гибкость без лишней сложности.
