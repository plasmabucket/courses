# Переменные и их значения

#### 15 улучшений кода по рекомендациям

Работал с решениями заданий к курсу ads1.

1) Задание 1: В методах класса LinkedList добавил `del ...` для переменных с которыми завершил работу.  
У класса LinkedList в методах используются переменные `node`, указывающие на текущие обрабатываемые узлы. Эти переменные используются для итерации в циклах по узлам списка, аналогично счётчику. После циклов эти переменные уже не нужны и, согласно рекомендации, следует присвоить им "недопустимые" значения. Вместо присвоений `node = None` после циклов решил использовать `del node` т.к. посчитал, что в Python так лучше отображается смысл "эту переменную использовать больше нельзя". К тому же, Python автоматически вызовет ошибку при использовании удалённой переменной, в отличии от использования переменной с "недопустимым" значением.  
Пример правки:
```
Было:

def find(self, val: Any) -> Node | None:
    node: Node | None = self.head
    while node is not None:
        ...
    ...


Стало:

def find(self, val: Any) -> Node | None:
    node: Node | None = self.head
    while node is not None:
        ...
    del node  # Удалил переменную после её использования
    ...
```
