# Имена переменных

12 примеров плохих имён, и их замена.

```
1) tree - branch_age_map
// Двумерный массив, хранящий возраст веток дерева.

2) destroyed - branch_destruction_map
// Двумерный массив булевых значений. Размечает ячейки в которых ветки должны быть уничтожены.

3) result - resulting_branch_map
// Двумерный массив символов. Содержит итоговую карту ячеек занятых ветками.

4) ind_l - index_of_descend_start
// Индекс элемента, с которого начинается убывающая подпоследовательность.

5) ind_r - index_of_descend_end
// Индекс элемента, на котором убывающая подпоследовательность заканчивается.

6) f_swap - team_composition_after_swap
// Массив номеров игроков после перестановки двух неупорядоченных элементов.

7) f_rev - team_composition_after_reverse
// Массив номеров игроков после обращения порядка элементов в подпоследовательности.

8) frequency - frequencies_of_chars
// Словарь, хранящий символы и их частоту в строке.

9) distribution - distribution_of_frequencies
// Словарь, хранящий значения частот символов и частоту этих значений.

10) dist_list - distribution_sorted_descending
// Массив, содержащий распределение частот, отсортированный по убыванию.

11) delta - number_of_less_frequent_frequencies
// Количество частот, отличающихся от самой многочисленной.

12) position - index_of_swap_target
// Индекс символа, который необходимо переставить на другую позицию.

```
