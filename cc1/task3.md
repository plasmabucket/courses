# Имена переменных

#### 7.1) Правильное именование булевых переменных

1) `first_val` - `is_first`  
Флаг в цикле, ищущем минимальное значение в массиве. Нужен для безусловного присваивания переменной-минимуму первого элемента массива. Новое имя более однозначно подразумевает ответ: "да/нет".

2) `first_set` - `is_first`  
Флаг в цикле, создающем пересечение нескольких множеств. Нужен для отделения первого в списке множества от логики пересечения.

3) `validity` - `walkers_detected`  
Из задачи про поиск Белых Ходоков. Хранит результат поиска -- обнаружены или нет.

4) `swap` - `is_num1_smaller`  
Флаг отношения двух чисел. Необходим для последующей их перестановки, в случае если первое меньше второго. Имя теперь более однозначное как булевое, конкретно отражает описываемую сущность и не опирается на реализацию.

5) `match` - `is_match`  
Флаг в функции поиска подсписка в упорядоченном списке. Хранит результат проверки -- совпадает ли подсписок с подсписком, выбранным из списка полного. Простое "match" не так явно отражает, что это -- булевая переменная. 


#### 7.2) Типичные имена булевых переменных

1) `cycle_broken` - `found`  
Флаг в цикле, ищущем решение уравнения перебором. Имя "found" более наглядно означает, что решение было найдено.

2)  `pop` - `pop_ok`  
Флаг в функции балансировки скобок. Отслеживает получилось ли достать очередную скобку из стека. Теперь более ясен смысл "успех/неудача".


#### 7.3) Индексы в циклах

Как и рекомендовано, использую `i`, `j` и `k` как имена индексов в циклах.

Также, активно использую встроенную возможность Python проводить итерацию по элементам вместо их индексов: `for char in my_string: ...`

Примеры:  

1) `for char in key: ...`
2) `for value in self.list: ...`
3) `for input_set in set_list: ...`
4) `for ind, item in enumerate(slots): ...`


#### 7.4) Пары-антонимы.

1) `min_index` / `max_index` - `left_bound` / `right_bound`  
Индексы левой и правой границ в бинарном поиске. Изменил названия для лучшей выразительности.

2) `prev` / `next`  
Имена полей у узла в двусвязном списке. Хранят указатели на предыдущий и следующий узлы.

3) `head` / `tail`  
Имена полей у связного списка. Хранят первый и последний узлы.


#### 7.5) Временные переменные

Ни в одном своём решении не создавал ни одну переменную, как временную. Поэтому использую примеры из кода, не написанного мной.  
Источник: https://github.com/kovidgoyal/calibre -- программа для управления личной библиотекой электронных книг.

1) `z` - `zip_archive`  
Переменная, хранящая объект-архив, в который записываются файлы.

2) `tmp` - `temp_folder_path`  
Путь к каталогу в который распаковываются файлы из архива. После распаковки файлы перемещаются из каталога и каталог удаляется.

3) `x` - `text_to_write`  
Переменная в функции, проверяющей кодировку текста. Содержит текст, который необходимо записать в файл.
