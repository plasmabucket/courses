### 12 улучшений кода с константами

#### Класс DynArray 

Правки в реализации динамического массива на Python:

1) Создал константу MIN_CAPACITY -- минимальный размер буфера динамического массива. Убрал магическое число "16" из формулы определения нового размера при уменьшении.

2) Создал константу INITIAL_CAPACITY -- исходный размер буфера. Убрал магическое число "16" в конструкторе класса. Не стал заменять это число на MIN_CAPACITY т.к. их смысл различается.

3) Создал константу GROWTH_FACTOR -- фактор увеличения размера буфера. Убрал магическое число "2" в двух методах.

4) Cоздал константу SHRINK_THRESHOLD -- порог при котором происходит уменьшение буфера. Заменил магическое число в условии для уменьшения.

5) Создал константу SHRINK_FACTOR -- фактор уменьшения размера буфера. Убрал магическое число и немного переделал формулу для возможности беспроблемно этот фактор изменять:  
`self.capacity * 2 // 3` -> `int(self.capacity * SHRINK_FACTOR)`.

Вынес эти идентификаторы в заголовок модуля и присвоил им тип `Final`.  
Теперь заголовок выглядит вот так:
```
...
from typing import Final

INITIAL_CAPACITY: Final[int] = 16
MIN_CAPACITY: Final[int] = INITIAL_CAPACITY
GROWTH_FACTOR: Final[int] = 2
SHRINK_THRESHOLD: Final[int] = 2
SHRINK_FACTOR: Final[float] = 1.5


class DynArray:
    ...
```


#### Класс DequeDynamic

По заданию нужно было создать деку с динамическим буфером на основе динамического массива, поэтому в классе DequeDynamic почти те же самые проблемы:

6) Создал константу MIN_CAPACITY -- минимальный размер буфера деки. Убрал магическое число "16" из формулы определения нового размера при уменьшении.

7) Создал константу INITIAL_CAPACITY -- исходный размер буфера деки. Убрал магическое число "16" в конструкторе класса.

8) Создал константу GROWTH_FACTOR -- фактор увеличения размера буфера. Убрал магическое число "2" в двух методах добавления элементов.

9) Cоздал константу SHRINK_THRESHOLD -- порог при котором происходит уменьшение буфера. Заменил магическое число в условии уменьшения в методах удаления элементов.

10) Создал константу SHRINK_FACTOR -- фактор уменьшения размера буфера. Убрал магическое число и подправил формулу уменьшения размера.

Новый заголовок:
```

from typing import Final

INITIAL_CAPACITY: Final[int] = 16
MIN_CAPACITY: Final[int] = INITIAL_CAPACITY
GROWTH_FACTOR: Final[int] = 2
SHRINK_THRESHOLD: Final[int] = 2
```

#### Класс BloomFilter

В классе есть два метода -- две хэш-функции, отличающиеся только числами в формуле вычисления хэша. Числа были помечены комментариями, но теперь вижу, что было бы намного лучше сделать их правильными константами.

11) Заменил число "17" константой FIRST_HASH_PRIME

12) Заменил число "223" константой SECOND_HASH_PRIME

Новый заголовок:
```
...
from typing import Final

FIRST_HASH_PRIME: Final[int] = 17
SECOND_HASH_PRIME: Final[int] = 223


class BloomFilter:
    ...
```
