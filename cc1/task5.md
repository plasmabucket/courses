# Имена классов

В своём коде подходящих примеров не нашёл, поэтому все примеры взяты из чужого кода.  
Источник: https://github.com/kovidgoyal/calibre


#### 3.1) Пять имён классов

1) `ParseRtf` - `RtfParser`
Парсер документов формата RTF. Глагол в имени сделал сущесвительным.

2) `Info` - `DocInfoConverter`
Изменил название -- сделал его более выразительным. Класс отвечает за конвертацию поля "info" из формата RTF в промежуточный формат для последующей генерации XML документа. Оставил слово "Info" т.к. оно отражает название поля в RTF документе.

3) `Data` - `OPF2Metadata`
Класс, содержащий два поля -- метаданные формата OPF2. Название теперь отвечает содержанию.

4) `Manager` - `ShortcutRegistry`
Класс, отвечающий за запись/удаление комбинаций клавиш для GUI.

5) `JobsManager` - `JobQueue`
Класс, отвечающий за очередь задач и их отображение в GUI. Убрал абстрактное слово "Manager".


#### 3.2) Семь имён методов

1) `get_metadata` - `fetch_metadata`
2) `download_metadata` - `fetch_metadata`
Три класса, относящиеся к GUI, имели методы, связанные с получением метаданных книги: `get_`, `fetch_`, и `download_`. Привёл их к одному слову "fetch". Все три связаны с загрузкой из интернета.

3) `fetch_cover_from_cache` - `get_cover_from_cache`
Т.к. "fetch" я присвоил методам, относящимся к загрузке из интернета, то этот метод переименовал в "get". Он получает обложки книг из кэша на устройстве.

4) `fetch_books_by_author` - `get_books_by_author`
Та же ситуация. Метод не подключается к интернету, а ищет книги в базе данных, поэтому переименовал в "get".

5) `fetch_eligible_custom_fields` - `get_eligible_custom_fields`
Нет подключения к интернету. Идёт чтение названий полей из локальной базы данных. Поэтому "fetch" -> "get"

6) `get_newest_version` - `fetch_newest_version`
Обратная ситуация. Идёт подключение к интернету для получения актуальной версии приложения. Переименовал в "fetch".

7) `fetch_covers` - `render_covers`
Вообще не относится к получению данных. Нет ни загрузки из интернета, ни чтения локальных файлов. Метод относится к рендерингу обложек книг, поэтому переименовал в "render".
